## 日本語

**アプリ名**（30 文字以内）

```
センターフライ 〜100球、全部捕れるか〜
```

**簡単な説明**（80 文字以内）

```
センターを守るあなたに100球のフライが飛んでくる！ダッシュ・ダイブ・ジャンプで全部捕れるか？3D野球ゲーム
```

**詳しい説明**

```
あなたはセンター。ナイター照明に照らされた満員のスタジアムで、ひたすらセンターフライが飛んでくる。
100球すべて捕れるか――外野手の腕の見せどころだ。

■ 打球を読んで、走って、飛びつけ
・カキーンという打球音と同時に、打球の方向と高さを読んで一歩目を踏み出せ
・頭上を越える大飛球は、早めに下がらないと間に合わない
・前に落ちるライナーは、ダイビングキャッチで飛びつけ
・フェンス際の打球は、フェンスの前でジャンプしてホームランキャッチ
・中盤からは風が吹き、打球が流される

■ 野手の背中越しの3D視点
・ホームラン競争を外野側から見たような、迫力のスタジアム
・打者・投手・満員のスタンド・照明塔を正面に見ながら打球を追う
・芝に落ちる打球の影と、右上のミニマップで落下点を見きわめる

■ アウトを取るたびに大歓声と花火
・トランペットと太鼓の応援、打球が上がると「おおおー」とどよめく
・アウトを取るたびに花火が上がり、大歓声と拍手
・ダイビングキャッチやホームランキャッチではエアホーンが鳴り響く
・10連続アウトごとに花火が追加。全球捕球なら花火の大連発

■ かんたん操作
・左下の方角リングで移動、右のボタンでダッシュ・ジャンプ・ダイブ
・捕球は自動。ボールが近づくと野手がグラブを差し出す
・自信がないときは「着地点ナビ」をオンに。地面の輪が落下点を教えてくれる

■ その他
・「草野球」から「伝説の名手」までの称号
・スコアと称号を友だちにシェア（ナビあり／なしも表示）
・オフラインでも遊べる（広告・シェアは通信が必要）
・日本語・英語対応

さあ、プレイボール。100球のフライ、全部捕れるか？
```
