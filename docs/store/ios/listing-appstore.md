# App Store 掲載情報（下書き）

App Store Connect の「配信」タブ（バージョン 1.0.0）と「App 情報」に貼り付けて使います。プライマリ言語は日本語、英語（U.S.）はローカライズとして追加します。
概要（説明文）は Google Play 用の `docs/store/listing.md`（日本語）・`docs/store/listing-en.txt`（英語）の「詳しい説明」をそのまま使えます。

---

## 日本語

**名前**（30 文字以内）

```
センターフライ 〜100球、全部捕れるか〜
```

**サブタイトル**（30 文字以内）

```
走って飛びつけ！外野守備3D野球ゲーム
```

**プロモーション用テキスト**（170 文字以内。審査なしで変更できる）

```
センターを守るあなたに100球のフライが飛んでくる！打球を読んでダッシュ、ダイビングキャッチ、フェンス際のホームランキャッチ。アウトを取るたびに花火と大歓声。100球全部捕れるか？
```

**キーワード**（100 文字以内。カンマ区切り、スペースなし）

```
野球,外野,フライ,キャッチ,守備,センター,ホームラン,スポーツ,3D,ダイビングキャッチ,ナイター,プロ野球
```

**概要**

`docs/store/listing.md` の「詳しい説明」をそのまま貼る。
